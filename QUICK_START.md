# 🎮 Quick Start Guide

## Play the Game in 3 Steps

### Step 1: Open the Game
Choose one of these methods:

**Method A: Local Server (Recommended)**
```bash
# In the repository directory, run:
python3 -m http.server 8000

# Then open in your browser:
# http://localhost:8000/matching-game.html
```

**Method B: Direct File**
```bash
# Simply open the file in your browser:
open matching-game.html
# or double-click matching-game.html
```

### Step 2: Select Difficulty
- **Easy**: 6 pairs (12 cards) - Perfect for beginners
- **Medium**: 10 pairs (20 cards) - Good challenge
- **Hard**: 15 pairs (30 cards) - Expert level

### Step 3: Start Playing!
1. Click "Start Game"
2. Click any card to reveal it
3. Click another card to try to match
4. Match all pairs to win!

## 🎯 Game Rules

### Matching
- Each **card name** must be matched with its **meaning**
- Click two cards to check if they match
- Correct matches stay revealed
- Wrong matches flip back face-down

### Scoring
- ✅ **+100 points** for each correct match
- ❌ **-10 points** for each wrong match
- 🎯 Try to maximize your accuracy!

### Winning
- Match all pairs to complete the game
- Review your statistics and missed pairs
- Learn from mistakes and play again!

## 📊 What Gets Tracked

- ⏱️ **Time**: How long it takes to complete
- 🎯 **Matches**: Number of successful pairs
- 🔢 **Attempts**: Total matching attempts
- 💯 **Score**: Points earned (100 per match, -10 per miss)
- 📈 **Accuracy**: Percentage of correct matches

## 💡 Pro Tips

1. **Focus First**: Try to remember card positions
2. **Read Carefully**: Meanings can be similar
3. **Learn Patterns**: Major Arcana have philosophical meanings
4. **Use Keywords**: They're hints to the full meaning
5. **Review Misses**: The end screen teaches you what you missed

## 🆘 Troubleshooting

**Problem**: Cards won't load / blank screen
- **Solution**: Use a local server (Method A above)
- **Reason**: Browsers block local file access to JSON

**Problem**: Game is too easy/hard
- **Solution**: Change difficulty level before starting

**Problem**: Want to restart mid-game
- **Solution**: Click "Reset Game" button

## 🎓 Learning Strategy

1. **Start Easy**: Begin with 6 pairs to learn
2. **Review Misses**: Pay attention to the review screen
3. **Increase Difficulty**: Move up when comfortable
4. **Repeat**: Play multiple times for memorization
5. **Focus on Suits**: Learn one suit at a time
